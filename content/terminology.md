# 核心术语对照

英文模型名、数据集名称、版本号和软件名保持原样，便于检索原版软件。

| English | 中文 | 说明 |
| --- | --- | --- |
| life cycle assessment / LCA | 生命周期评价（LCA） | 全文统一“评价” |
| life cycle inventory / LCI | 生命周期清单（LCI） | inventory 非“库存” |
| life cycle inventory analysis | 生命周期清单分析 | |
| life cycle impact assessment / LCIA | 生命周期影响评价（LCIA） | |
| dataset | 数据集 | |
| activity | 活动 | 过程型活动可说明“活动（过程）” |
| process / unit process | 过程 / 单元过程 | |
| unit process raw data / UPR | 单元过程原始数据（UPR） | 与 linked LCI 区分 |
| undefined / unlinked dataset | 未指定系统模型 / 未链接的数据集 | 依上下文区分，不笼统译成“未定义” |
| exchange | 交换 | ecoinvent 数据结构用语 |
| elementary flow | 基本流 | 生态环境部公开技术资料的用语 |
| elementary exchange | 基本流交换 | 与自然环境的输入、输出 |
| intermediate exchange | 中间交换 | 过程间交换的产品和服务 |
| technosphere | 技术圈 | |
| reference product / reference exchange | 参考产品 / 参考交换 | 保留数据库含义；不将 reference product 与 functional unit 混淆 |
| by-product | 副产品 | |
| material for treatment / MFT | 待处理材料（MFT） | 不展开为“多功能处理” |
| municipal solid waste / MSW | 城市固体废物（MSW） | |
| allocation | 分配 | 环境负荷分配，非计算机内存分配 |
| allocation key / factor | 分配依据 / 分配因子 | |
| attributional | 归因型 | |
| consequential | 后果型 | 保留 Consequential 模型名 |
| Allocation, cut-off by classification | 按分类截断的分配模型（Allocation, cut-off by classification） | 简称 Cut-off 模型 |
| Allocation, cut-off, EN15804 | EN15804 截断分配模型（Allocation, cut-off, EN15804） | |
| Allocation at the point of substitution / APOS | 替代点分配模型（APOS） | |
| Substitution, consequential, long-term | 长期后果型替代模型（Substitution, consequential, long-term） | |
| subdivision | 过程细分 | |
| substitution | 替代 | |
| burden / burden-free | 环境负荷 / 不承担上游环境负荷 | 依句义，不误译成“完全没有环境影响” |
| credit / credits | 环境收益（抵扣） | 非信用、积分 |
| cut-off | 截断 | |
| recycled content | 再生材料含量 | 方法名称结合上下文说明 |
| recyclable product | 可回收产品 | |
| end-of-waste | 废物终止状态 | 欧盟法规特定概念，保留英文术语并注明原文含义 |
| waste treatment / treatment activity | 废物处理 / 处理活动 | |
| market activity / market dataset | 市场活动 / 市场数据集 | 模型中的供需连接，不仅指商业交易 |
| market mix / technology mix | 市场组合 / 技术组合 | |
| market group | 市场组 | |
| transforming activity | 转化活动 | |
| constrained market | 受约束市场 | |
| marginal supplier / technology | 边际供应商 / 边际技术 | |
| system boundary / system model | 系统边界 / 系统模型 | |
| characterization factor / CF | 表征因子（CF） | |
| impact category / indicator | 影响类别 / 指标 | |
| midpoint / endpoint | 中点 / 终点 | |
| area of protection / AoP | 保护领域（AoP） | |
| carbon footprint / water footprint | 碳足迹 / 水足迹 | |
| global warming potential / GWP | 全球变暖潜势（GWP） | |
| emission factor | 排放因子 | |
| biogenic / fossil carbon | 生物源碳 / 化石碳 | |
| non-fossil carbon | 非化石碳 | 不自动改为“生物源碳”，除非原文明确 |
| dry mass / wet mass | 干质量 / 湿质量 | |
| water content / water in wet mass | 含水率 / 湿质量中的水质量 | 原文公式以干质量为分母，不能改为湿基定义 |
| lower / higher heating value | 低位 / 高位热值 | |
| exergy | 㶲 | 不译成能量或熵 |
| pedigree matrix | 数据质量谱系矩阵 | |
| uncertainty / basic uncertainty | 不确定性 / 基础不确定性 | |
| geometric mean / arithmetic mean | 几何平均值 / 算术平均值 | |
| standard deviation / variance | 标准差 / 方差 | 不混淆 |
| lognormal distribution | 对数正态分布 | |
| confidence interval | 置信区间 | |
| Monte Carlo simulation | 蒙特卡洛模拟 | |
| geography / geographic scope | 地理区域 / 地理范围 | |
| inheritance / parent / child dataset | 继承 / 父数据集 / 子数据集 | |
| environmental product declaration / EPD | 环境产品声明（EPD） | |
| scope 1 / 2 / 3 | 范围 1 / 2 / 3 | GHG Protocol 语境 |
| cradle-to-gate / cradle-to-grave | 从摇篮到大门 / 从摇篮到坟墓 | |
| XML | 可扩展标记语言（XML） | 原站 glossary-x 的 Extended 有误，W3C 正式全称 Extensible Markup Language |
