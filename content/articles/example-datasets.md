### <strong>数据集的构成</strong> <a href="#zh-b0019" id="zh-b0019"></a>

#### <strong>内容</strong> <a href="#zh-b0020" id="zh-b0020"></a>

每个数据集代表一个活动（例如，“cotton production”是表示棉纤维生产的转化活动）。

- 至少一个参考产品，例如“cotton fibre”（棉纤维）。

- 元数据：数据集的描述和文档，包括数据来源以及创建数据集所用建模方法的说明。
- 所有相关[中间交换](glossary-i.md)的清单，即来自和流向技术圈的交换，例如“electricity, low voltage”（低压电力）或“diesel”（柴油）的输入。
- 所有相关[基本流交换](glossary-e.md)的清单，即来自和流向环境的交换，例如二氧化碳、向空气排放及其他排放、土地占用和土地转化。

#### <strong>结构</strong> <a href="#zh-b0026" id="zh-b0026"></a>

每个数据集包括以下部分：

- <strong>活动信息（Activity Information）</strong>：包含数据集的全部一般信息、文档和元数据。
- <strong>交换（Exchanges）</strong>：包含数据集与技术圈和生物圈之间的实际交换。
- <strong>交换属性（Exchange properties）</strong>：此部分列出每个交换相应的[属性](properties.md)。
- <strong>累积 LCIA 结果（Cumulative LCIA results）</strong>（仅在 LCIA 视图中）：此部分列出 ecoinvent 数据库中实施的各 LCIA 方法所对应的[LCIA 结果](upr-lci-lcia.md)。

### <strong>Setup of a Dataset</strong> <a href="#en-b0019" id="en-b0019"></a>

#### <strong>Content</strong> <a href="#en-b0020" id="en-b0020"></a>

Every dataset represents one activity (for example “cotton production” is a transforming activity that represents the production of cotton fibre).

- at least one reference product (such as “cotton fibre”)

- metadata (description and documentation of the dataset, including a description of sources and the modeling approach to create the dataset)
- a list of all relevant [intermediate exchanges](glossary-i.md), “from” and “to” the Technosphere (such as input of “electricity, low voltage” or “diesel”)
- a list of all relevant [elementary exchanges](glossary-e.md), “from” and “to” the Environment (such as carbon dioxide, emissions to air and other emissions, land occupation and transformation)

#### <strong>Structure</strong> <a href="#en-b0026" id="en-b0026"></a>

Each dataset includes the following sections:

- <strong>Activity Information</strong>: Contains all general information, documentation and metadata of the dataset.
- <strong>Exchanges</strong>: Contains the actual exchanges of the dataset with the technosphere and biosphere.
- <strong>Exchange properties</strong>: For each exchange, the corresponding [properties](properties.md) are listed in this section.
- <strong>Cumulative LCIA results</strong> (in LCIA view only): This section lists the [LCIA results](upr-lci-lcia.md) for the LCIA methods implemented in the ecoinvent database.
