### ID <a href="#zh-b0009" id="zh-b0009"></a>

标识符（Identifier）的缩写。

### 继承 <a href="#zh-b0011" id="zh-b0011"></a>

将父数据集的字段内容传递给子数据集。ecoinvent 第 3 版数据库只允许地理继承，即某些地区数据集（例如巴西大豆生产）可以建模为全球数据集的子数据集。

父数据集中的数值发生变化时，子数据集中的数值也会自动变化。

### 中间交换 <a href="#zh-b0014" id="zh-b0014"></a>

两个活动之间的交换，其流动始终位于技术圈内，既不排放到环境，也不从环境中获取。

### 国际标准产业分类 <a href="#zh-b0016" id="zh-b0016"></a>

联合国用于经济数据分类的体系。ISIC 是研究经济现象、提高数据国际可比性、指导制定国家分类体系，以及促进健全国家统计体系发展的基本工具（联合国）。ISIC 提供活动和产品分类体系，ecoinvent 第 3 版采用了该体系。

### IO <a href="#zh-b0018" id="zh-b0018"></a>

投入产出（Input Output）的缩写，指一种经济模型。

### ISIC <a href="#zh-b0020" id="zh-b0020"></a>

国际标准产业分类（International Standard Industrial Classification）的缩写。

### ISO <a href="#zh-b0022" id="zh-b0022"></a>

国际标准化组织的缩写（原文英文为 International Organization of Standardization）。

### ID <a href="#en-b0009" id="en-b0009"></a>

Abbreviation for Identifier

### Inheritance <a href="#en-b0011" id="en-b0011"></a>

Passing on of field contents from a parent dataset to a child dataset. Only geographical inheritance is allowed in the ecoinvent version 3 database, i.e. some regional datasets (such as Brazilian soybean production) might be modeled as a child dataset of the global dataset.

When a value is changed in the parent dataset it is automatically changed in the child dataset as well.

### Intermediate Exchange <a href="#en-b0014" id="en-b0014"></a>

An exchange between two activities that stays within the technosphere and is not emitted to or taken from the environment.

### International Standard Industrial Classification <a href="#en-b0016" id="en-b0016"></a>

The United Nations system for classifying economic data. ISIC is a basic tool for studying economic phenomena, fostering international comparability of data, providing guidance for the development of national classifications and for promoting the development of sound national statistical systems (UN). ISIC provides a classification system for activities and products that ecoinvent has adopted for version 3.

### IO <a href="#en-b0018" id="en-b0018"></a>

Abbreviation for Input Output, economic model

### ISIC <a href="#en-b0020" id="en-b0020"></a>

Abbreviation for International Standard Industrial Classification

### ISO <a href="#en-b0022" id="en-b0022"></a>

Abbreviation for International Organization of Standardization
