### TCDD <a href="#zh-b0012" id="zh-b0012"></a>

四氯二苯并二噁英（tetra-chlor-dibenzo-dioxin）的缩写。

### TDS <a href="#zh-b0014" id="zh-b0014"></a>

总溶解性固体（Total Dissolved Solids）的缩写。

### 技术圈（Technosphere） <a href="#zh-b0016" id="zh-b0016"></a>

表示全部人类活动。某个活动的交换可以发生于该活动与环境之间（基本流交换，例如向大气排放 CO2），也可以发生于两个活动之间（中间交换，例如一个活动向另一个活动——废水处理——排出的废水）。

### TOC <a href="#zh-b0018" id="zh-b0018"></a>

总有机碳（Total Organic Carbon）的缩写。

### 流向环境（To Environment） <a href="#zh-b0020" id="zh-b0020"></a>

表示交换的类型（来源）。这是作为活动输出存在的基本流交换（与环境之间的交换）。

### 流向技术圈（To Technosphere） <a href="#zh-b0022" id="zh-b0022"></a>

表示交换的类型（来源）。这是作为活动输出存在的中间交换（与技术圈之间的交换）。

### TPM <a href="#zh-b0024" id="zh-b0024"></a>

总颗粒物（Total Particulate Matter）的缩写。

### 转化活动（Transforming Activity） <a href="#zh-b0026" id="zh-b0026"></a>

将输入转化为不同于输入的输出的人类活动。这是 ecoinvent 数据库中最常见的活动类型，例如将地下硬煤转化为可销售产品硬煤的煤矿，或将金属、塑料和能源转化为汽车的汽车工厂。

### 处理活动（Treatment Activity） <a href="#zh-b0028" id="zh-b0028"></a>

参考产品带负号的转化活动，实际上表示该活动提供处理或处置参考产品的服务。例如，废塑料处理活动的参考产品为 -1 kg 废塑料。处理活动的名称总是以“treatment of …”（处理……）开头。

### TSS <a href="#zh-b0030" id="zh-b0030"></a>

总悬浮固体（Total Suspended Solids）的缩写。

### TCDD <a href="#en-b0012" id="en-b0012"></a>

Abbreviation for tetra-chlor-dibenzo-dioxin

### TDS <a href="#en-b0014" id="en-b0014"></a>

Abbreviation for Total Dissolved Solids

### Technosphere <a href="#en-b0016" id="en-b0016"></a>

Represents all human activities. An exchange of a certain activity can be between the activity and the environment (elementary exchange, for example CO2 emission to air) or between two activities (intermediate exchange, for example wastewater to be released from one activity to another—treatment of wastewater).

### TOC <a href="#en-b0018" id="en-b0018"></a>

Abbreviation for Total Organic Carbon

### To Environment <a href="#en-b0020" id="en-b0020"></a>

Represents the type (origin) of an exchange. This is an elementary exchange (with the environment) present as an output of an activity.

### To Technosphere <a href="#en-b0022" id="en-b0022"></a>

Represents the type (origin) of an exchange. This is an intermediate exchange (with the technosphere) present on the output of an activity.

### TPM <a href="#en-b0024" id="en-b0024"></a>

Abbreviation for Total Particulate Matter

### Transforming Activity <a href="#en-b0026" id="en-b0026"></a>

A human activity that transforms inputs into outputs that are different from the inputs. This is the most common type of activity in the ecoinvent database, e.g. a hard coal mine that transforms hard coal in ground to the marketable product hard coal, or an automobile plant that turns metals, plastics and energy into cars.

### Treatment Activity <a href="#en-b0028" id="en-b0028"></a>

A transforming activity with a reference product with a negative sign, which effectively means that the activity is supplying the service of treating or disposing of the reference product. E.g. the reference product of treatment of waste plastic activity is -1 kg of waste plastic. The name of a treatment activity always start with “treatment of …” phrase.

### TSS <a href="#en-b0030" id="en-b0030"></a>

Abbreviation for Total Suspended Solids
