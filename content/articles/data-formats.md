### 什么是 ecoSpold2 格式？ <a href="#zh-b0003" id="zh-b0003"></a>

ecoSpold2 格式用于创建 ecoinvent 第 3 版的生命周期清单。该格式规定了标准生命周期清单中哪些字段是必填的、哪些字段是可选的。

请在[此处](ecospold2.md)进一步了解 ecoSpold2 格式。

### openLCA 要求 .zolca 文件时，如何使用 ecoinvent 的 .spold 文件？ <a href="#zh-b0006" id="zh-b0006"></a>

openLCA 是 GreenDelta 公司发布的 LCA 软件，该公司也是 ecoinvent 数据库的经销商。openLCA 使用专有的 .zolca 文件格式存储数据集。要在 openLCA 中使用 ecoinvent 数据库，必须将数据库集成到软件中。此过程只能由 GreenDelta 完成。请联系其支持团队启动此过程。

### What is the ecoSpold2 Format? <a href="#en-b0003" id="en-b0003"></a>

The ecoSpold2 format is used to create life cycle inventories for ecoinvent version 3. This format sets up standards on what are mandatory and what are optional fields for a standard life cycle inventory.

Learn more about the ecoSpold2 format [here](ecospold2.md).

### How Can I Use ecoinvent’s .spold Files When openLCA Asks for .zolca Files? <a href="#en-b0006" id="en-b0006"></a>

openLCA is an LCA software published by the company GreenDelta and is a reseller of the ecoinvent database. In openLCA, they use the proprietary file format .zolca to store datasets. To use the ecoinvent database with openLCA, the database has to be integrated into the software. This process can only be done by GreenDelta. Please contact their support to initiate this process.
