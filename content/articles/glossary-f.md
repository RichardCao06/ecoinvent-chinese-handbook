### FOB <a href="#zh-b0006" id="zh-b0006"></a>

船上交货（Free On Board）的缩写。

### 淡水 <a href="#zh-b0008" id="zh-b0008"></a>

盐浓度较低的水。

### 来自环境 <a href="#zh-b0010" id="zh-b0010"></a>

表示交换的类型（来源）。这是作为活动投入存在的基本流交换（与环境之间的交换）。

### 来自技术圈 <a href="#zh-b0012" id="zh-b0012"></a>

表示交换的类型（来源）。这是作为活动投入存在的中间交换（与技术圈之间的交换）。

### FOB <a href="#en-b0006" id="en-b0006"></a>

Abbreviation for Free On Board

### Fresh Water <a href="#en-b0008" id="en-b0008"></a>

Water having low concentration of salts.

### From Environment <a href="#en-b0010" id="en-b0010"></a>

Represents the type (origin) of an exchange. This is an elementary exchange (with the environment) present as an input of an activity.

### From Technosphere <a href="#en-b0012" id="en-b0012"></a>

Represents the type (origin) of an exchange. This is an intermediate exchange (with the technosphere) present on the input of an activity.
