### <strong>ecoEditor</strong> <a href="#zh-b0012" id="zh-b0012"></a>

ecoinvent 网站提供的一款免费软件。建议使用此工具创建 ecoSpold2 格式的生命周期清单（LCI）数据集，并向 ecoinvent 数据库提交 LCI 数据。

### <strong>ecoinvent 数据库第 2 版</strong> <a href="#zh-b0014" id="zh-b0014"></a>

ecoinvent 数据库的较早版本。

### <strong>ecoinvent 数据库第 3 版</strong> <a href="#zh-b0016" id="zh-b0016"></a>

ecoinvent 数据库的当前版本。

### <strong>ecoQuery</strong> <a href="#zh-b0018" id="zh-b0018"></a>

一个网页用户界面，所有 ecoinvent 数据库用户都可通过该界面访问数据库（需要注册）。通常通过生命周期评价（LCA）软件工具（如 openLCA、SimaPro 或 GaBi）访问 ecoinvent 数据库的用户，也始终可以通过 ecoQuery 访问数据库。未购买 ecoinvent 许可证的用户仍可注册为访客，查看数据库中所有可用数据集的元数据（描述）。

在此登录：[https://ecoquery.ecoinvent.org/](https://ecoquery.ecoinvent.org/Account/LogOn?ReturnUrl=%2f)

### <strong>ecoSpold 格式</strong> <a href="#zh-b0021" id="zh-b0021"></a>

ecoSpold 是 ecoinvent 用于创建生命周期清单的一种格式名称。该格式规定了标准生命周期清单的必填字段和可选字段。ecoSpold 1 格式用于 ecoinvent 第 1 版和第 2 版，ecoSpold2 格式则用于 ecoinvent 第 3 版。ecoSpold2 格式提供了许多旧版 ecoSpold1 格式中没有的新字段，例如数学关系、变量名称或交换的属性。

[ecoSpold2 格式](ecospold2.md)

### <strong>基本流交换</strong> <a href="#zh-b0024" id="zh-b0024"></a>

与自然、社会或经济环境之间的交换。例如：来自自然界的未经加工的投入，向空气、水和土壤的排放，物理影响，以及在指定条件下的工作时数。

### <strong>蒸发</strong> <a href="#zh-b0026" id="zh-b0026"></a>

水从液态转变为气态的过程。

### <strong>蒸发率</strong> <a href="#zh-b0028" id="zh-b0028"></a>

过程中蒸发的水量与进入该过程的水量之比。

### <strong>蒸散</strong> <a href="#zh-b0030" id="zh-b0030"></a>

植被覆盖地表通过土壤蒸发和植物蒸腾这两个过程共同发生的水分蒸发。

### <strong>交换</strong> <a href="#zh-b0032" id="zh-b0032"></a>

交换有两种基本类型：基本流交换和中间交换。

### <strong>ecoEditor</strong> <a href="#en-b0012" id="en-b0012"></a>

A software available for free on the ecoinvent website. This tool is recommended to be used to create LCI datasets in ecoSpold2 format and submitting LCI data to the ecoinvent database.

### <strong>ecoinvent Database Version 2</strong> <a href="#en-b0014" id="en-b0014"></a>

An older version of the ecoinvent database.

### <strong>ecoinvent Database Version 3</strong> <a href="#en-b0016" id="en-b0016"></a>

The current version of the ecoinvent database.

### <strong>ecoQuery</strong> <a href="#en-b0018" id="en-b0018"></a>

A web user interface through which all the users of the ecoinvent database can access the database (registration required). Users who usually access the ecoinvent database through LCA software tools (such as openLCA, SimaPro, or GaBi) can also always access the ecoinvent database through ecoQuery. Users who did not purchase the ecoinvent license can still register as guests and see the meta data (description) of all the datasets available in the database.

Login at [https://ecoquery.ecoinvent.org/](https://ecoquery.ecoinvent.org/Account/LogOn?ReturnUrl=%2f)

### <strong>ecoSpold Format</strong> <a href="#en-b0021" id="en-b0021"></a>

ecoSpold is a name for a format used by ecoinvent to create life cycle inventories. This format sets up standards on what are mandatory and what are optional fields for a standard life cycle inventory. While the ecoSpold 1 format is used for ecoinvent version 1 and 2, it is the ecoSpold2 format for ecoinvent version 3. The ecoSpold2 format offers many new fields, such as mathematical relation, variable names or properties of an exchange which were not available in the older ecoSpold1 format.

[ecoSpold2 format](ecospold2.md)

### <strong>Elementary Exchange</strong> <a href="#en-b0024" id="en-b0024"></a>

Exchange with the natural, social or economic environment. Examples: Unprocessed inputs from nature, emissions to air, water and soil, physical impacts, working hours under specified conditions.

### <strong>Evaporation</strong> <a href="#en-b0026" id="en-b0026"></a>

The process in which water changes from a liquid to a gas state.

### <strong>Evaporation Rate</strong> <a href="#en-b0028" id="en-b0028"></a>

The ratio of the amount of water evaporated during the process to the amount of water entering the process.

### <strong>Evapotranspiration</strong> <a href="#en-b0030" id="en-b0030"></a>

The evaporation of water from a vegetated surface through the combined processes of soil evaporation and plant transpiration.

### <strong>Exchange</strong> <a href="#en-b0032" id="en-b0032"></a>

Two basic types of exchanges exist – elementary exchanges and intermediate exchanges.
