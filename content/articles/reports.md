## ecoQuery 右上方的“报告”（Reports）部分存放选定项目的补充信息。以下报告可供下载： <a href="#zh-b0002" id="zh-b0002"></a>

2024 年 2 月 1 日

ecoQuery 右上方的“报告”（Reports）部分存放选定项目的补充信息。以下报告仅可凭有效的 ecoinvent 许可证下载：

- <strong>Allocation, cut-off, EN15804\_documentation.pdf：</strong>此文档记录 ecoinvent v3.8 的 EN15804 截断分配模型（“Allocation, cut-off, EN15804”）中各指标的计算方法。
- <strong>Consideration of land use change in ecoinvent version 3.3.pdf：</strong>此文档介绍 ecoinvent v3.3 所采用的土地利用变化（LUC）核算方法。
- <strong>ecoinvent 2.2 translated reports\_06\_Energy Systems.zip：</strong>此文件包含第 2 版有关能源系统的报告的英文译本。

- <strong>ecoinvent 3 report\_Agriculture.zip：</strong>此文件包含若干 .pdf 报告和 xlsx 文件，涉及 ecoinvent v3 中的农业部门。
- <strong>ecoinvent 3 report\_electricity India.pdf：</strong>此文档记录印度发电技术和电网的区域化生命周期清单。
- <strong>ecoinvent 3 report\_Life cycle inventories for the treatment of iron and steel industry by-products.pdf：</strong>此报告涵盖 ecoinvent 数据库中钢铁工业副产品处理的生命周期清单数据，同时考虑资源回收和处置两类途径。
- <strong>ecoinvent 3 report\_Life cycle inventories of pyrometallurgical copper production and anode slime processing.pdf：</strong>此报告概述原生铜火法冶金以及阳极泥处理的生命周期清单数据集。
- <strong>ecoinvent 3 report\_Refrigerated Transport.pdf：</strong>此报告概述使用联运集装箱的货运，以及为需要受控气氛的货物配备相应设备的货运。

- <strong>ecoinvent 3 report\_selected chapters\_Energy.zip：</strong>此文件包含电力行业相关讨论页面的内容。
- <strong>ecoinvent 3 report\_Transport Default Model\_Global.pdf：</strong>此报告记录 ecoinvent v3 中美国和 EU27 各商品组的默认运输数据。
- <strong>ecoinvent 3 report\_Transport Default Model\_Switzerland.zip：</strong>此文件包含一个列出瑞士各商品组默认运输数据的 .xlsx 文件，以及配套 .pdf 报告。
- <strong>ecoinvent 3 report\_Update of the European natural gas supply chains.pdf：</strong>此报告详述 ecoinvent v3.4 中欧洲天然气供应链更新所依据的假设和信息。
- <strong>ecoinvent 3.3 open access datasets\_PDF documentation.zip：</strong>提供一组可免费获取的 PDF 格式数据集样例。

- <strong>ecoinvent 3.4 open access datasets\_PDF documentation.zip：</strong>提供一组可免费获取的 PDF 格式数据集样例。
- <strong>Ökoinventar Transporte\_Grundlagen für den ökologischen Vergleich von Transportsystemen.pdf：</strong>此报告是 ecoinvent 运输数据的重要来源。

ecoinvent 第 2 版的所有其他报告也可在[ecoQuery](https://db.ecoinvent.org/)的“报告”（reports）部分获取。

## The Reports section, on the top right in ecoQuery, is a repository of additional information for selected projects. The following reports are available for download: <a href="#en-b0002" id="en-b0002"></a>

Feb 1st, 2024

The Reports section, on the top right in ecoQuery, is a repository of additional information for selected projects. The following reports are available for download, only with a valid ecoinvent licence:

- <strong>Allocation, cut-off, EN15804\_documentation.pdf:</strong> This document provides a documentation on the calculation of the indicators in the “Allocation, cut-off, EN15804” system model for ecoinvent v3.8.
- <strong>Consideration of land use change in ecoinvent version 3.3.pdf:</strong> This document describes the LUC accounting method applied to ecoinvent v3.3.
- <strong>ecoinvent 2.2 translated reports\_06\_Energy Systems.zip:</strong> This file contains version 2 reports on Energy system that have been translated to English.

- <strong>ecoinvent 3 report\_Agriculture.zip: </strong>This file contains several .pdf reports and xlsx files dealing with the agricultural sector in ecoinvent v3.
- <strong>ecoinvent 3 report\_electricity India.pdf:</strong> This document provides a documentation of regionalized Life Cycle Inventory of Power Producing Technologies and Power Grids in India.
- <strong>ecoinvent 3 report\_Life cycle inventories for the treatment of iron and steel industry by-products.pdf:</strong> This report covers the life cycle inventory data for the treatment of iron and steel industry by-products in the ecoinvent database, considering both recovery and disposal routes.
- <strong>ecoinvent 3 report\_Life cycle inventories of pyrometallurgical copper production and anode slime processing.pdf:</strong> This report provides an overview of the life cycle inventory datasets for the pyrometallurgical processing of primary copper and the processing of anode slimes.
- <strong>ecoinvent 3 report\_Refrigerated Transport.pdf:</strong> This report serves as an overview of freight transport using intermodal shipping containers and freight transport equipped for the transport of cargo in need of controlled atmosphere.

- <strong>ecoinvent 3 report\_selected chapters\_Energy.zip:</strong> This file contains the content of talk pages concerning the electricity sector.
- <strong>ecoinvent 3 report\_Transport Default Model\_Global.pdf:</strong> This report provides a documentation of default transport data per commodity group for the US and EU27 for ecoinvent v3.
- <strong>ecoinvent 3 report\_Transport Default Model\_Switzerland.zip:</strong> This file contains an .xlsx file with default transport data per commodity group for Switzerland and an associated .pdf report.
- <strong>ecoinvent 3 report\_Update of the European natural gas supply chains.pdf:</strong> This report details the underlying assumptions and information used for the update of the natural gas supply chains in Europe for ecoinvent v3.4.
- <strong>ecoinvent 3.3 open access datasets\_PDF documentation.zip:</strong> Represents a sample of datasets in pdf format available free of charge.

- <strong>ecoinvent 3.4 open access datasets\_PDF documentation.zip:</strong> Represents a sample of datasets in pdf format available free of charge.
- <strong>Ökoinventar Transporte\_Grundlagen für den ökologischen Vergleich von Transportsystemen.pdf:</strong> This report is a key source for transport data in ecoinvent.

All further reports on ecoinvent version 2 are also available in the “reports” section of [ecoQuery](https://db.ecoinvent.org/).
